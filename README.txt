30-DAY STRENGTH PLAN APP (installable, works offline)

An installable app needs to be hosted once on a free HTTPS site. After that it works offline.

1. Put ALL files from this folder on a free host, for example GitHub Pages
   (create a repo, upload the files, turn on Pages) or Netlify Drop.
   Keep the files together in the same folder.
2. On your phone, open the site link in Chrome or Samsung Internet.
3. Wait a few seconds, then menu (three dots) -> Install app / Add to Home screen.
4. Open it from your home screen. After the first load it works with no internet.

Notes:
- Your logs are saved on the phone itself. Use Guide -> Backup now and then.
- Clearing browser data erases them, so copy a backup first.
- Updating the app: change the cache name in sw.js (strength-v1 -> strength-v2) and re-upload.
